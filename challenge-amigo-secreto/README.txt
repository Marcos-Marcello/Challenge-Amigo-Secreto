Challenge Amigo Secreto
Um programa feito de muito suor e estresse (já que estou aprendendo). Sorteia nomes aleatórios para qualquer atividade. 

O Que Faz?
Adiciona nomes em uma lista
Mostra todos os nomes que você adicionou
Sorteia um nome aleatório quando você clica no botão

Como Usar (Passo a Passo)
Baixe os 3 arquivos:

index.html
style.css
app.js

Coloque todos na mesma pasta no seu computador

Abra o index.html no navegador (clique 2 vezes nele)

Digite um nome na caixinha
Clique em "Adicionar"
Repita até colocar todos os nomes
Clique em "Sortear Amigo" para ver o sorteado

Se Der Errado...
Verifique se os 3 arquivos estão na mesma pasta

Olhe o console do navegador (F12 > Console)
